# Release Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the ten-section pre-release checklist and cut `0.4.0` — proving, with tests and a
committed audit, that architectural authority cannot change silently, the five skills' existing
workflows have not regressed, migration cannot lose a decision without a trace, and no deterministic
rule is reported verified without a checker that actually ran.

**Architecture:** SP6 adds no new runtime capability. It adds a `test/` layer that drives the runtime
SP2–SP5 already shipped (`runtime/checkers/`, `runtime/migration/`, `runtime/drift/`,
`runtime/baseline/`) against small fixture repositories, one Layer-1 regression net over the five
skills' frozen bytes, and a `docs/` layer that turns the previously-external pre-release checklist
into a committed, per-line-audited artifact.

**Tech Stack:** Node ESM (`.mjs`), `node:test`, zero runtime dependencies, Markdown copied
byte-for-byte, no new packages.

**Spec:** `docs/superpowers/specs/2026-09-09-sp6-release-hardening-design.md`

**Depends on (already shipped by the time this plan starts):** SP2 `runtime/checkers/` (0.3.2), SP3
`runtime/drift/` and the hook manifest (0.3.5), SP4 `runtime/migration/` (0.3.6), SP5
`skills/threat-model/` and its checker bindings (0.3.7). The build order actually executed was
SP2 → SP3 → SP4 → SP5 → SP6, not the SP2 → SP4 → SP5 → SP3 → SP6 this upgrade was originally planned
around (`0.3.3` and `0.3.4` were never cut — see `docs/release-0.4.0.md`'s SP → version mapping
table). This plan cites those modules by the interface shapes
`docs/superpowers/specs/2026-09-09-upgrade-decisions-sp2-sp6.md` commits to. Where a shipped signature
differs in a harmless way (an extra flag, a renamed field), fix the call site here — the assertions
are what this plan is actually protecting, not the exact spelling of a CLI flag.

## Global Constraints

- **Zero dependencies.** No package may be added to `package.json`. Node builtins only.
- **No prose templating.** Markdown is copied byte-for-byte. Never substitute tokens into a `.md`
  file.
- **Canonical bytes are frozen — the original four.** `agentic-patterns`, `decide-architecture`,
  `design-patterns`, `test-patterns` frontmatter (`name`, `description`) must stay byte-identical to
  their 0.3.1 values. `threat-model` (SP5) has no such snapshot — it is new at 0.4.0.
- **Never hand-edit `build/`.** Regenerated by `npm run build -- --target all`.
- **No new `runtime/` code.** This is the sub-project's own defining constraint (D5 in the design
  spec) — everything here is `test/` or `docs/`.
- **Deterministic fixtures.** Every new test must produce the same result on a shuffled fixture
  listing and on a rerun; no timestamps, SHAs, or host paths asserted into generated output.
- **Code style:** ESM, 2-space indent, double-quoted strings, named exports — match
  `builders/build.mjs` and `test/build.test.mjs`.
- **Version target:** `0.4.0` in `package.json`, only in the final task, only after every earlier task
  passes.
- **Test command:** `npm test` currently runs
  `node --test test/build.test.mjs test/baseline.test.mjs test/scenarios.test.mjs`. Every new suite
  this plan creates must be added to that script.

### One deviation from the spec, decided up front

The spec (D3/D4) says E2E-1 and the generic deterministic-checker corpus "share one fixture family."
Mechanically, that means `test/e2e/bind-and-prove.test.mjs` and the multi-tool corpus in Task 8 both
read fixtures from `test/fixtures/checkers/`, and `test/fixtures/e2e/bind-and-prove/` is one specific
scenario *within* that tree (`test/fixtures/checkers/import-linter/e2e/`) rather than a sibling
directory that happens to duplicate its contents. This plan builds the corpus tree first (Task 8) and
has E2E-1 (Task 3) point into it, not the order the spec narrates them in.

```js
import assert from "node:assert/strict";
import { createHash } from "node:crypto";
import { readFile } from "node:fs/promises";
import { join, resolve } from "node:path";
import { fileURLToPath } from "node:url";
import { test } from "node:test";

const repositoryRoot = resolve(fileURLToPath(new URL("..", import.meta.url)));
const skillsRoot = join(repositoryRoot, "skills");

const frozen = JSON.parse(
  await readFile(join(repositoryRoot, "test/fixtures/skill-freeze/frontmatter-0.3.1.json"), "utf8"),
);

// Hardcoded on purpose, matching the house pattern in build.test.mjs and
// scenarios.test.mjs: the manifest must be updated by a deliberate edit, or
// this suite would grade a body change against itself.
const bodyManifest = JSON.parse(
  await readFile(join(repositoryRoot, "test/fixtures/skill-freeze/body-manifest.json"), "utf8"),
);

function splitFrontmatter(text) {
  const match = /^---\n([\s\S]*?)\n---\n([\s\S]*)$/.exec(text);
  assert.ok(match, "SKILL.md does not open with a frontmatter block");
  return { block: match[1], body: match[2] };
}

for (const [name, expected] of Object.entries(frozen)) {
  test(`${name}'s frozen frontmatter is byte-identical to its 0.3.1 shape`, async () => {
    const text = await readFile(join(skillsRoot, name, "SKILL.md"), "utf8");
    const { block } = splitFrontmatter(text);
    const nameLine = /^name:\s*(.+)$/m.exec(block)[1].trim();
    const description = block.slice(block.indexOf("description:")).replace(/^description:\s*/, "").trim();
    assert.equal(nameLine, expected.name, `${name}'s frontmatter 'name' changed since 0.3.1`);
    assert.equal(
      description,
      expected.description,
      `${name}'s frontmatter 'description' changed since 0.3.1 — triggering behaviour is part of the shipped release`,
    );
  });
}

test("every packaged skill's body hash matches the committed manifest", async () => {
  const names = Object.keys(bodyManifest).sort();
  for (const name of names) {
    const text = await readFile(join(skillsRoot, name, "SKILL.md"), "utf8");
    const { body } = splitFrontmatter(text);
    const hash = createHash("sha256").update(body).digest("hex");
    assert.equal(
      hash,
      bodyManifest[name],
      `${name}/SKILL.md body changed and test/fixtures/skill-freeze/body-manifest.json was not updated — ` +
        `update the manifest deliberately and note the change in the release notes`,
    );
  }
});

test("the body manifest names every currently packaged skill", async () => {
  const { readdir } = await import("node:fs/promises");
  const packaged = (await readdir(skillsRoot, { withFileTypes: true }))
    .filter((entry) => entry.isDirectory())
    .map((entry) => entry.name)
    .sort();
  assert.deepEqual(Object.keys(bodyManifest).sort(), packaged);
});
```

```js
import assert from "node:assert/strict";
import { execFile } from "node:child_process";
import { join, resolve } from "node:path";
import { fileURLToPath } from "node:url";
import { promisify } from "node:util";
import { test } from "node:test";

const execFileAsync = promisify(execFile);
const repositoryRoot = resolve(fileURLToPath(new URL("..", import.meta.url)));
const checkerCli = join(repositoryRoot, "runtime/checkers/check-rules.mjs");
const corpus = join(repositoryRoot, "test/fixtures/checkers");

async function runChecker(fixture, args = [], env = process.env) {
  try {
    const { stdout } = await execFileAsync(
      process.execPath,
      [checkerCli, "--dir", join(corpus, fixture), "--json", ...args],
      { cwd: repositoryRoot, env },
    );
    return { code: 0, rows: JSON.parse(stdout) };
  } catch (error) {
    return { code: error.code, rows: JSON.parse(error.stdout || "[]") };
  }
}

const withoutImportLinter = { ...process.env, PATH: process.env.PATH.split(":").filter(
  (segment) => !segment.includes("import-linter"),
).join(":") };

test("a satisfied deterministic rule reports pass and exits 0", async () => {
  const { code, rows } = await runChecker("import-linter/pass", ["--run"]);
  assert.equal(code, 0);
  assert.equal(rows.find((r) => r.rule === "svc-db-isolation").status, "pass");
});

test("a violated deterministic rule reports fail and exits 2", async () => {
  const { code, rows } = await runChecker("import-linter/fail", ["--run"]);
  assert.equal(code, 2);
  assert.equal(rows.find((r) => r.rule === "svc-db-isolation").status, "fail");
});

test("a rule naming a nonexistent contract reports unbound and exits 2, never pass", async () => {
  const { code, rows } = await runChecker("import-linter/unbound", ["--run"]);
  assert.equal(rows.find((r) => r.rule === "svc-db-isolation").status, "unbound");
  assert.equal(code, 2);
});

test("a config the reader cannot parse reports unreadable-config with a line number, not a silent pass", async () => {
  const { code, rows } = await runChecker("import-linter/unreadable-config", ["--run"]);
  const row = rows.find((r) => r.rule === "svc-db-isolation");
  assert.equal(row.status, "unreadable-config");
  assert.match(row.evidence, /line \d+/);
  assert.equal(code, 2);
});

test("a missing tool reports unavailable and does not block by default", async () => {
  const { code, rows } = await runChecker("import-linter/unavailable", ["--run"], withoutImportLinter);
  assert.equal(rows.find((r) => r.rule === "svc-db-isolation").status, "unavailable");
  assert.equal(code, 0);
});

test("--require-tools promotes unavailable to blocking", async () => {
  const { code } = await runChecker("import-linter/unavailable", ["--run", "--require-tools"], withoutImportLinter);
  assert.equal(code, 2);
});

test("without --run, resolution is static only and nothing is spawned", async () => {
  const { code, rows } = await runChecker("import-linter/pass");
  assert.equal(code, 0);
  const row = rows.find((r) => r.rule === "svc-db-isolation");
  assert.ok(["pass", "resolved"].includes(row.status) === false || row.evidence.includes(".importlinter"));
});
```

- [x] **Step 1: Write the shared E2E support module**

Create `test/e2e/support.mjs`:

```js
import { cp, mkdtemp, readFile, rm, writeFile } from "node:fs/promises";
import { tmpdir } from "node:os";
import { join, resolve } from "node:path";
import { fileURLToPath } from "node:url";

export const repositoryRoot = resolve(fileURLToPath(new URL("../..", import.meta.url)));

export async function cloneFixture(relativePath) {
  const source = join(repositoryRoot, "test/fixtures", relativePath);
  const dest = await mkdtemp(join(tmpdir(), "arch-crew-e2e-"));
  await cp(source, dest, { recursive: true });
  return dest;
}

export async function withPatch(path, patch, fn) {
  const original = await readFile(path, "utf8");
  try {
    await writeFile(path, patch(original), "utf8");
    await fn();
  } finally {
```
